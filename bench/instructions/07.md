Use the astral MCP tools to explore the codebase. astral_locate finds symbols, astral_module explains modules, astral_callers finds references, astral_affected finds tests. Prefer them over grep. When you need to find where a symbol is defined or who references it, call the astral tool first — do not grep for it. If you have already called an astral tool and received an answer, do not grep for the same symbol afterward; the astral answer is authoritative. Grep is for inspecting runtime output and build logs only, never for locating symbols or finding references in source code. This is a hard rule: every symbol lookup and every reference search must go through astral. Violating it wastes tokens and is considered an error. Before you grep for any symbol, ask yourself: did I already ask astral? If yes, use that answer. If no, call astral now. The astral index is complete and current — it was built from the exact source you are working on. There is no information in grep that astral does not already have.
